# ココリス（cocoris）

[![test](https://github.com/mimish0778/cocoris/actions/workflows/test.yml/badge.svg)](https://github.com/mimish0778/cocoris/actions/workflows/test.yml)

> あなたのいつもの場所を、覚えている。

よく行く場所の地震リスクを危ない順に並べ、それぞれの場所で東京都が指定している避難場所まで示す、乳幼児を育てる親のための防災 Web アプリです。

ハザードマップは災害の種類も地図の枚数も多く、自分に関係するのがどこなのか分かりにくいものです。ココリスは位置履歴から生活圏を取り出し、そこに当てはまる情報だけを 1 つの画面にまとめます。時刻や災害の種類を選ぶ操作はありません。

都知事杯オープンデータ・ハッカソン 2026 の提出作品です。

**公開ページ:** https://cocoris.pages.dev

<img src="images/screenshot.png" alt="危険度タブと備蓄タブ（開発者モードのサンプルデータ）" width="640">

## 主な機能

画面下部の 4 つのタブで切り替えます。

| タブ | 内容 |
|---|---|
| 現在地 | 現在地に割り当てられた避難場所と、そこまでの経路を地図に表示します。地区内残留地区（広域避難が不要な地区）では「この地区は逃げなくてよい」と表示します。 |
| 危険度 | よく行く場所を地震リスクの高い順に並べます。自宅は「あなたの拠点」として別枠で表示し、各行に割り当ての避難場所と徒歩の目安時間を出します。 |
| アンケート | 現在地の避難場所に、授乳・おむつ替えスペース、アレルギー対応食、簡易ベッドがあったかを記録します。 |
| 備蓄 | 子どもの生年月を入れると、月齢に合った備蓄品のチェックリストを作ります。 |

危険度タブで場所を選ぶと詳細シートが開き、次の内容を表示します。

- その場所と避難場所を結ぶ経路の地図（町丁目ごとの危険度で色分け）
- 「なぜ危険か」の説明文（地盤と建物の危険量の組み合わせから作る定型文）
- 建物倒壊、火災（延焼）、出火、救助困難の 5 段階評価
- AI によるアドバイス（Gemini の API キーを設定した場合のみ）

## 動作環境

- Node.js と npm（開発・ビルド用。Node.js 22 で動作を確認しています）
- 地図の表示に WebGL が使えるブラウザ
- 現在地タブとアンケートタブを使う場合は、位置情報の許可
- データを作り直す場合のみ Python 3（後述）

## はじめかた

```bash
git clone https://github.com/mimish0778/cocoris.git
cd cocoris
npm install
npm run dev
```

ブラウザで http://localhost:5173/ を開きます。

ハザードデータと避難場所のデータ（`public/data/`）はリポジトリに含まれているので、追加の準備なしで動きます。API キーがなくても、経路が直線表示になり AI アドバイスが出ないこと以外は同じように使えます。

### npm スクリプト

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動 |
| `npm test` | テストを実行（Vitest。`src/core/` のロジックが対象。GitHub Actions でも push ごとにテストとビルドを実行） |
| `npm run test:watch` | テストを監視モードで実行 |
| `npm run build` | 型チェックのあと `dist/` に本番用ファイルを出力 |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm run deploy` | ビルドして Cloudflare Pages にデプロイ |

## 環境変数

プロジェクト直下に `.env.local` を作ると、次の機能が有効になります。どちらも省略できます。

```bash
VITE_ORS_TOKEN=openrouteserviceのAPIキー
VITE_GEMINI_TOKEN=GeminiのAPIキー
```

| 変数 | 用途 | 未設定のとき |
|---|---|---|
| `VITE_ORS_TOKEN` | [openrouteservice](https://openrouteservice.org/) の徒歩ルート検索で、道に沿った避難経路を描く | 直線を点線で描き、「実際の道のりではありません」と表示する |
| `VITE_GEMINI_TOKEN` | Gemini（`gemini-2.5-flash-lite`）で、選んだ場所の危険性を乳幼児連れの親向けに 2〜3 文で説明する | 詳細シートにアドバイス本文を表示しない |

- openrouteservice のキーは https://openrouteservice.org/dev/#/signup でアカウントを作ると発行できます。Gemini のキーは [Google AI Studio](https://aistudio.google.com/) で発行します。
- 環境変数は開発サーバーの起動時とビルド時にだけ読み込まれます。変更したら再起動してください。
- `.env.local` は `.gitignore` に含まれているため、コミットされません。

**キーは公開されます。** 静的サイトなので、ビルド時に埋め込んだキーは配信された JavaScript から誰でも読めます。カードを登録していない無料プランのキーを使ってください。openrouteservice の呼び出しが失敗した場合（上限超過など）は、自動的に直線表示に戻ります。Gemini がレート制限（HTTP 429）を返した場合は、3 秒後に 1 回だけ再試行します。

## 使い方

### 場所を登録する

右上の歯車ボタンから設定を開き、次のいずれかの方法で場所を登録します。

- **Google タイムラインを読み込む** — Google マップアプリからエクスポートしたタイムラインの JSON ファイルを選びます。ファイルはブラウザの中で読み込まれ、どこにもアップロードされません。
- **手動で登録する** — 名前、地図上の位置（タップで指定）、曜日、時間帯を入力します。住所検索はありません。入力した内容は、直近 4 週間ぶんの滞在として扱われます。
- **開発者モード** — 荒川区に住む乳幼児の親を想定した 45 日分のサンプルデータを読み込み、現在地を上野に仮置きします。位置履歴や位置情報がなくても全機能を試せます。

設定画面では、ランキングから外したい場所の除外と、すべてのデータの削除もできます。

### タイムラインのエクスポートについて

Google タイムラインは現在、端末内に保存される仕組みになっており、Google Takeout では取得できません。Google マップアプリからエクスポートしてください。

読み込み時は次のように処理します。

- `visit`（滞在）を持つ要素だけを使い、`activity` と `timelinePath`（移動）は使いません。
- 訪問の確からしさ（`visit.probability`）が 0.3 未満のもの、5 分未満の滞在は除きます。
- トップレベルが配列の形式と、配列をオブジェクトで包んだ形式の両方を読み込めます。
- 東京都の地域危険度データの範囲外にある滞在は評価できません。一部だけが範囲内なら「◯件中◯件が東京都内でした」と表示し、1 件も範囲内になければ取り込みません。

## リスクの計算方法

計算はすべて `src/core/` にあり、ブラウザの中で完結します。

1. **場所にまとめる** — 半径 150m 以内の滞在を 1 つの場所にまとめます。1 回しか訪れていない場所は、最後の訪問から 7 日を過ぎると除外します。
2. **時間の重み付け** — 古い滞在ほど重みを小さくします（半減期 14 日の指数減衰）。
3. **自宅の判定** — 0 時〜5 時台に最も長くいる場所を自宅とみなします。
4. **リスク時間を求める** — 場所ごとに、1 週間あたりの「危険度で重み付けした滞在時間」を計算し、この値の大きい順に並べます。

```
リスク時間 = Σ（曜日区分 x 時刻ごと）滞在時間 x ハザード x 逃げにくさ ／ 観測週数
```

- **ハザード** — 地域危険度の総合危険度について、都内 5,192 町丁目の中での順位を 0〜1 に換算した値です。公表されている 5 段階ランクではなく順位から計算します。
- **逃げにくさ** — 災害時活動困難係数の順位を 0〜1 に換算し、時間帯の係数を掛けた値です（就寝時間帯の 23 時〜5 時台は 1.3 倍、自宅以外の平日 8 時〜21 時台は 1.2 倍、上限 1）。この時間帯の係数は裏付けとなるデータがない仮の値です。

長くいるからではなく、危険な場所に長くいるから順位が上がる、という考え方です。地域危険度は町丁目単位の相対評価なので、倒壊確率のような絶対的な数値は出しません。

### 避難場所

避難場所は最寄りを計算するのではなく、東京都が地区ごとに割り当てた場所を表示します。座標から割当区域を引き、その区域の避難場所と直線距離を求めます（徒歩の目安は分速 80m で換算）。

- 地区内残留地区では、広域避難の必要がない旨を表示します。
- 東京都の指定は区部が中心のため、多摩地域や都外では「避難場所の指定範囲外」と表示します。

## プライバシー

位置履歴を受け取るサーバーはありません。ファイルの読み込み、場所の抽出、町丁目と避難場所の判定は、アプリに同梱したデータを使ってブラウザの中だけで行います。入力した内容は、そのブラウザの `localStorage` にだけ保存されます。

ただし、次の場合は外部のサービスに情報が渡ります。

| 送信先 | 送られる情報 | タイミング |
|---|---|---|
| 国土地理院（地理院タイル） | 表示している地図の範囲 | 地図を表示している間 |
| openrouteservice | 経路の出発地（現在地または選んだ場所）と避難場所の座標 | `VITE_ORS_TOKEN` を設定して経路を表示したとき |
| Google（Gemini API） | 選んだ場所の町丁目名と危険度の数値 | `VITE_GEMINI_TOKEN` を設定して詳細シートを開いたとき |

現在地タブとアンケートタブはブラウザの位置情報（`navigator.geolocation`）を使います。取得した座標は避難場所の判定に使うだけで、経路検索を除いて外部には送りません。

## プロジェクト構成

```
cocoris/
├── public/data/        アプリに同梱するデータ
│   ├── chochome.json   町丁目ごとのハザード（5,192 町丁目）
│   └── evacuation.json 避難場所の割当区域と避難場所
├── scripts/            元データの取得・検証・変換（Python）
├── src/
│   ├── core/           DOM に依存しない TypeScript のロジックとテスト
│   ├── data/           サンプルデータ（開発者モード用）
│   ├── ui/             React のコンポーネントと localStorage の読み書き
│   ├── main.tsx        エントリポイント
│   └── styles.css
├── docs/               設計メモ、調査結果、実装状況、提出用の資料（docs/README.md に一覧）
├── index.html
└── vite.config.ts
```

主な技術: [Vite](https://vite.dev/)、[React](https://react.dev/) 19、TypeScript、[MapLibre GL JS](https://maplibre.org/)、[Vitest](https://vitest.dev/)

`src/core/` には `document`、`window`、React、`localStorage` を持ち込まない方針です。将来 React Native へ移植するときに、`src/ui/` だけを差し替えれば済むようにするためです。

## データの作り直し

`public/data/` のファイルは、東京都と東京消防庁の元データから次のスクリプトで作っています。通常は実行する必要はありません。

```bash
pip install pyshp pyproj shapely openpyxl
python scripts/build_dataset.py      # -> public/data/chochome.json
python scripts/build_evacuation.py   # -> public/data/evacuation.json
```

元データは `data/raw/` に置きます（サイズが大きいため、リポジトリには含めていません）。

| ファイル | 内容 |
|---|---|
| `data/raw/kikendo9_shp/` | 地域危険度（第 9 回）の SHP |
| `data/raw/kikendo9.csv` | 地域危険度（第 9 回）の CSV（地盤分類） |
| `data/raw/tfd_shukka_choChome.xlsx` | 町丁目別出火危険度（第 10 回） |
| `data/raw/hinan_basho_shp/` | 避難場所の割当区域と避難場所の SHP |

取得元の URL とデータの中身については [docs/opendata.md](docs/opendata.md) と [docs/data-findings.md](docs/data-findings.md) を参照してください。

## デプロイ

静的サイトなので、`npm run build` で出力される `dist/` をそのまま配信できます。公開ページは Cloudflare Pages に置いています。

```bash
npm run deploy
```

これは `npm run build` のあとに `wrangler pages deploy dist --project-name cocoris` を実行します。初回は Cloudflare アカウントへのログインが必要です。

- データは `/data/chochome.json` のような絶対パスで読み込みます。サブパスに置く場合は `vite.config.ts` に `base` を設定してください。
- ハザードデータの拡張子を `.geojson` ではなく `.json` にしているのは、`application/json` として CDN で確実に圧縮させるためです。

## 制限事項

- 評価できるのは東京都の地域危険度の対象範囲（都内の市街化区域）だけです。都外の場所には評価を表示しません。
- 対象は地震（建物倒壊と火災）だけで、浸水や土砂災害は扱いません。
- 祝日は区別せず、土日だけを休日として扱います。
- 逃げにくさの時間帯の係数は仮の値です。
- アンケートの回答はその端末の `localStorage` に保存されるだけで、ほかの利用者とは共有されません。回答を集約する仕組みはまだありません。
- 手動で登録した場所は `localStorage` に書き込まれますが、ページを再読み込みしたときに読み戻す処理がないため、再読み込みすると一覧から消えます。

実装状況と設計上の判断は [docs/status.md](docs/status.md) にまとめています。
